## 4. 장비·환경 사실과 미확인 사항

- 사용자 전달 장비: Orbbec Astra Mini, Astra Mini Pro. 이는 사용자 제공 사실이며 실물 연결로 확인한 사실은 아니다.
- Linear에는 RealSense 기록이 남아 있다. 어떤 장비로 최신 결정했는지 확인 필요. 임의로 RealSense 구현이나 Orbbec SDK를 선택하지 않는다.
- 실행 호스트: Windows NT `10.0.26200.0`, PowerShell, Python `3.11.15`.
- 발견된 Python 경로: `C:/Users/user/AppData/Local/hermes/hermes-agent/venv/Scripts/python.exe`. 프로젝트 전용 가상환경이 아니다.
- 이 인터프리터의 `importlib.metadata`에서 `pyorbbecsdk`, `openni`, `primesense`, `pyrealsense2`, `numpy`, `pytest` 배포 패키지 미설치. `python -m pip show ...`는 pip 모듈이 없어 실패했으며, 이후 metadata 조회로 범위를 한정해 확인했다.
- 시스템 전체의 native SDK·드라이버·장치 연결 여부는 조사하지 못했다. 위 결과로 “PC에 SDK가 전혀 없다”고 일반화하지 않는다.
- SDK/API를 호출하거나 설치하지 않았다. 설치 버전을 특정할 수 없으므로 버전 대응 공식 API 문서 검증도 아직 미실행이다. 승인 후 장비·SDK 버전을 확인하고 그 버전의 제조사 공식 지원표·API 문서를 기록한 다음 사용한다. 휴대폰 지원 여부는 미확인이다.

남은 미확정 사항은 기존 질문 2~8번에 유지했다: 승인 규격·환경 의미·장비 모델/SDK·입력 형식/단위·보정·시간/자세·부피 적용 가정·실제 샘플/기준 부피/허용 오차. height field 가정과 완전 관측·footprint 요구는 여전히 **제안**이며 승인으로 바꾸지 않았다. 실제 샘플/기기 결과도 만들어내지 않았다.

| 자료 | 예정 소유·이관 방식 |

| 각 PR 초안 | 각각 해당 PR 본문 작성에 활용. 초안 파일 자체는 필수 이관 대상 아님 |

팀 PR을 별도로 만들 경우 ADE-54의 공유 문서 선행 반영 또는 기존 공통 규격을 기준으로 ADE-55 base를 정한다. 로컬 root commit을 팀 PR base로 사용하지 않는다. 팀 브랜치 이름·기본 브랜치·PR 생성은 아직 확정/수행하지 않았다.

공식 URL을 받은 뒤의 준비 절차:

1. 프로젝트를 지목하는 팀 문서/사용자 확인과 저장소의 실제 소속을 대조한다. `main`, `master`, `develop` 중 어느 것이 기본/PR 대상인지 이름으로 추측하지 않고 원격 HEAD 및 팀 규칙으로 확인한다.
2. 현재 폴더 밖의 **존재하지 않는 새 대상 폴더**를 정해 별도 clone한다. 기존 경로·문서·Git 이력은 보존하고 unrelated histories merge나 root commit 전체 cherry-pick을 하지 않는다.
3. clone의 remote URL·default branch·HEAD·working tree, 적용 AGENTS.md·README·개발 문서·의존성·테스트·입력 코드·공통 규격·승인 기록을 조사한다. 학교 PC 미push 코드는 별도 제공 자료로만 확인한다.
4. 실제 저장소 구조와 기존 문서에서 대응 위치를 찾아 이관 매핑을 갱신한다. 단순 7개 일괄 복사 대신 승인 규격과 충돌하는 제안을 제거/수정하고 동일 내용의 기존 문서에는 필요한 변경만 반영한다.
5. 팀 규칙의 별도 문서 작업 브랜치에서 승인 여부를 명시한 검토안을 완성하고 링크·예제·diff만 검사한다. 이번 범위의 구현·push·PR 생성·Linear 변경·메시지·병합은 수행하지 않는다.

지금 사용자에게 필요한 정보는 **인지동 공식 저장소 URL**이다. 가능하면 기본/PR 대상 브랜치와 근거, ADE-51 승인 자료 위치, 학교 PC 미push 작업의 유무·별도 제공 위치를 함께 요청한다. 나머지 장비/스키마/샘플 질문은 팀장 검토 문서에 모았으며 저장소 조사로 답이 확인되면 중복 질문하지 않는다.
